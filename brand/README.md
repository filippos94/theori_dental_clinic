# Theori Dental Clinic: logo files

**Concept:** a molar outline with a smile where the crossbar of the Greek letter Θ (theta) would be.
It combines the clinic's initial, its Greek and Cypriot roots, and the promise "Smile, you're in good hands".

All files are vector SVGs with the lettering converted to shapes. They need no fonts installed and scale to any size.

| File | Use |
|---|---|
| `theori-logo-horizontal.svg` | Primary logo (website header, letterhead, documents) |
| `theori-logo-horizontal-white.svg` | On dark or photo backgrounds |
| `theori-logo-horizontal-greek.svg` | Greek descriptor "ΟΔΟΝΤΙΑΤΡΕΙΟ" |
| `theori-logo-stacked.svg` | Square spaces, signage |
| `theori-mark.svg` | App icon, social profile picture |
| `theori-mark-outline.svg` | Mark only, teal line (light backgrounds) |
| `theori-mark-mono-black.svg` | One-colour printing, engraving, stamps |
| `favicon.svg` | Browser tab icon (heavier line for small sizes) |
| `brand-guide.html` | Brand page: versions, mock-ups, colours, type and usage rules (open in a browser) |

**Colours:** Theori Teal `#176A6D`, Deep Ink `#0F2A33`, Slate `#4A5F66`, Mist `#DCEDED`, Sand `#F3EADB`, Porcelain `#FAFAF7`
**Type:** Manrope Bold (name and headings), Inter SemiBold (descriptor and text). Both are free Google Fonts with Greek.

**Minimum sizes:** full logo 120 px / 30 mm wide; mark alone 16 px / 6 mm. Don't stretch, recolour or add effects.
